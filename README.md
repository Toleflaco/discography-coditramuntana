# Discography Management System

Prueba técnica para Coditramuntana. Sistema de gestión de discografía
con CRUD de artistas y LPs, y reporte agregado.

## Stack

- Java 21
- Spring Boot 4.x
- Spring Data JPA
- H2 Database (file mode)
- Maven

## Requisitos

- JDK 21
- Maven 3.9+ (o usar el wrapper incluido `./mvnw`)

## Arranque

```bash
./mvnw spring-boot:run
```

La aplicación arranca en `http://localhost:8080`.

## Tests

```bash
./mvnw verify
```
